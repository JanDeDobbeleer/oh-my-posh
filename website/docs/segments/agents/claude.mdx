## What

Display Claude Code session information including the current AI model, token usage, costs, and workspace details.
Shows a visual gauge of context window usage and formatted cost/token information for monitoring your Claude usage.

This segment integrates with [Claude Code's statusline functionality][claude-docs]
to provide real-time session data in your prompt.

:::info Working directory

`oh-my-posh claude` renders directory-aware segments — `path`, `git`, `project` and the language segments — and the
`.PWD`, `.Folder` and `.AbsolutePWD` template values against the directory the payload reports in
`workspace.current_dir`, falling back to `cwd`. When the payload reports neither, or reports a path that is not an
existing absolute directory, the renderer's own working directory is used, as before.

The renderer's working directory itself is not changed, so external commands — including version manager shims — and
the `cmd`, `readFile` and `glob` template functions still resolve relative to the directory Claude Code started the
renderer in, not to `workspace.current_dir`.

:::

#### PromptCache Properties

Statistics for the main conversation's [prompt cache][prompt-cache]. Access via `.PromptCache`.
The object is `nil` until the first API response of the session and requires Claude Code v2.1.251 or later;
fields marked v2.1.260 additionally require Claude Code v2.1.260 or later.
Timestamps are Unix epoch seconds.

| Name                    | Type                | Description                                                                                         |
| ----------------------- | ------------------- | --------------------------------------------------------------------------------------------------- |
| `.Warm`                 | `bool`              | Whether the cached prefix is still within its TTL                                                   |
| `.CachingObserved`      | `bool`              | Whether any response reported cache tokens; `false` means caching is off or not reported            |
| `.TTL`                  | `string`            | Cache lifetime of the current cached prefix: `5m` or `1h`                                           |
| `.ExpiresAt`            | `*int64`            | When the cached prefix goes cold; nil when the last response reported no cache tokens               |
| `.Requests`             | `int`               | API requests recorded for the main conversation                                                     |
| `.Misses`               | `int`               | Requests that re-processed content the cache already held                                           |
| `.ExpectedRebuilds`     | `int`               | Cache rebuilds that followed a compaction or a clearing of old tool results                         |
| `.HitRatio`             | `*float64`          | Cache read tokens as a fraction (0-1) of all input tokens; nil while no tokens were counted         |
| `.CacheWriteTokens`     | `int`               | All tokens written to the cache this session                                                        |
| `.MissRecacheTokens`    | `int`               | Tokens written to the cache by requests counted as misses                                           |
| `.LastMissAt`           | `*int64`            | When the last miss happened; nil while there are no misses                                          |
| `.LastMissCause`        | `LastMissCause`     | Likely cause of the last miss; nil when there is none or it is unknown (v2.1.260)                   |
| `.MissCauses`           | `map[string]int`    | Number of diagnosed misses per cause (v2.1.260)                                                     |
| `.RecacheTokensIfCold`  | `*int`              | Tokens the next request re-caches if the cache goes cold; nil right after a compaction              |

#### LastMissCause Properties

| Name               | Type       | Description                                                                                        |
| ------------------ | ---------- | -------------------------------------------------------------------------------------------------- |
| `.Causes`          | `[]string` | Cause names, such as `tools_changed`, `system_prompt_changed`, `ttl_expired_5m`, `likely_server_side` |
| `.ToolsAdded`      | `int`      | Tools added to the request, reported with `tools_changed`                                          |
| `.ToolsRemoved`    | `int`      | Tools removed from the request, reported with `tools_changed`                                      |
| `.SystemCharDelta` | `int`      | Change in system prompt length in characters, reported with `system_prompt_changed`                |

:::tip Prompt cache example
Guard against the object being absent so older Claude Code versions keep working:

```template
{{ if .PromptCache }}{{ .PromptCacheGauge }} {{ .PromptCacheHitRatio }}%{{ if not .PromptCache.Warm }} cold{{ end }}{{ end }}
```

:::

### Percentage Methods

The `Percentage` type (returned by `.TokenUsagePercent`, `.FiveHourUsage`, `.SevenDayUsage`)
provides additional methods for direct use in templates:

| Method       | Returns  | Description                                                        |
| ------------ | -------- | ------------------------------------------------------------------ |
| `.Gauge`     | `string` | Visual gauge showing remaining capacity using hardcoded `▰`/`▱` characters |
| `.GaugeUsed` | `string` | Visual gauge showing used capacity using hardcoded `▰`/`▱` characters |
| `.String`    | `string` | Numeric percentage value (e.g., "75" for use in templates)         |

:::tip Custom gauge characters
Use `.TokenGauge`, `.TokenGaugeUsed`, `.FiveHourGauge`, and `.SevenDayGauge` instead of the
raw `.Percentage` methods above — they respect the `gauge_marked_char` and `gauge_unmarked_char` options.
:::

## How it works

The segment reads session information from the `POSH_CLAUDE_STATUS` environment variable, which is automatically set when using the `oh-my-posh claude` command. The data includes:

- Current AI model information
- Token usage and context window utilization
- Session costs and duration
- Workspace directory information

The segment only displays when Claude Code is actively providing session data.
